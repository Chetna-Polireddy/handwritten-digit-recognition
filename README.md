# Neural Network-Based Handwritten Digit Recognition

An AI project that uses an Artificial Neural Network (ANN) to recognize handwritten digits from 0 to 9 using the MNIST dataset.

## 📌 Project Details

- Dataset: MNIST
- Training Images: 60,000
- Testing Images: 10,000
- Image Size: 28 × 28 pixels
- Model: Artificial Neural Network
- Architecture: 784 → 128 → 64 → 10
- Optimizer: Adam
- Epochs: 10
- Test Accuracy: 97.81%

## 🛠️ Technologies Used

Python, TensorFlow, Keras, NumPy, Scikit-learn, Streamlit
